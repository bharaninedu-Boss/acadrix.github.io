1. MA25C02 — Linear Algebra

Official scope: Vector spaces; linear transformations and diagonalization; inner product spaces; matrix decomposition. The curriculum specifies software-supported activities and simple matrix problems up to 3 × 3 for decomposition topics.

Unit 1 — Vector spaces

A vector space is a set of objects called vectors that can be added and multiplied by scalars while satisfying the vector-space axioms. Common examples include R², R³ and polynomial spaces.

A linear combination of vectors v₁,…,vₙ is c₁v₁+…+cₙvₙ. The span is the set of all possible linear combinations. A set is linearly independent when the equation c₁v₁+…+cₙvₙ=0 has only the trivial solution c₁=…=cₙ=0.

For A = [v₁ v₂ … vₙ], independence ⇔ rank(A) = number of columns.

A basis is a linearly independent set that spans the space. The number of vectors in a basis is its dimension.

Worked example — independence

Take v₁=(1,2), v₂=(2,4). Since v₂=2v₁, one vector is a multiple of the other. The set is linearly dependent and does not form a basis of R².

For u₁=(1,0), u₂=(0,1), neither is a multiple of the other and they span R². They form the standard basis, so dim(R²)=2.

Unit 2 — Linear transformations and diagonalization

A transformation T is linear if T(u+v)=T(u)+T(v) and T(cv)=cT(v). Its null space contains vectors mapped to zero; its range contains all output vectors. The dimension theorem states dim(domain)=dim(null space)+dim(range).

For a square matrix A, an eigenvector v is non-zero and satisfies Av=λv. The scalar λ is the eigenvalue. Find eigenvalues from det(A−λI)=0, then solve (A−λI)v=0 for eigenvectors.

A matrix is diagonalizable when it has enough linearly independent eigenvectors to form a basis. Then A=PDP⁻¹, where D is diagonal and the columns of P are eigenvectors.

Unit 3 — Inner product spaces

The standard inner product in Rⁿ is u·v=Σuᵢvᵢ. The norm is ||u||=√(u·u). Two vectors are orthogonal when their inner product is zero.

Cauchy–Schwarz inequality: |u·v| ≤ ||u|| ||v||. Gram–Schmidt converts a linearly independent set into an orthogonal (or, after normalization, orthonormal) set.

Gram–Schmidt method

  1. Set u₁=v₁.
  2. Subtract the projection of v₂ onto u₁: u₂=v₂−[(v₂·u₁)/(u₁·u₁)]u₁.
  3. For later vectors, subtract projections onto every earlier orthogonal vector.
  4. Normalize each vector if an orthonormal basis is required.

Unit 4 — Matrix decomposition

Orthogonal diagonalization applies to real symmetric matrices. Positive definite matrices satisfy xᵀAx>0 for every non-zero x. QR decomposition expresses A=QR, where Q has orthonormal columns and R is upper triangular.

Singular Value Decomposition (SVD) expresses A=UΣVᵀ. The diagonal entries of Σ are non-negative singular values. Least-squares methods find x that minimizes ||Ax−b||² when an exact solution may not exist.

Software practice: Use MATLAB or an open-source equivalent to compute rank, null space, eigenvalues, eigenvectors, QR and SVD. Explain what the output means; do not submit software output without interpretation.

2. CS25C06 — Digital Principles and Computer Organization

Official scope: Digital logic and Karnaugh maps; computer-system structure and performance; ALU and arithmetic circuits; instruction-set architecture and pipelining; memory hierarchy and I/O systems.

Logic foundations

Digital systems represent information using binary values 0 and 1. A logic gate performs a Boolean operation. AND gives 1 only when all inputs are 1; OR gives 1 when at least one input is 1; NOT complements the input. NAND and NOR are universal gates because any Boolean function can be built using only NAND gates or only NOR gates.

Boolean expressions can be represented as Sum of Products (SOP) or Product of Sums (POS). Karnaugh maps group adjacent 1s (for SOP) or 0s (for POS) in groups of 1, 2, 4, 8… cells. Don't-care entries may be used when they simplify the expression without changing required outputs.

Computer system and performance

A computer contains a processor, memory, input/output units and interconnection pathways. Von Neumann architecture generally uses a shared memory for instructions and data; Harvard architecture uses separate instruction and data memories.

The instruction cycle commonly includes fetch, decode, execute and write-back stages. Performance terms include CPI (cycles per instruction), MIPS (million instructions per second) and MFLOPS (million floating-point operations per second).

CPU time = Instruction count × CPI × Clock cycle time

When comparing processors, do not rely on clock frequency alone: instruction count and average CPI also matter.

ALU and arithmetic circuits

Combinational circuits include half adders, full adders, parallel adders, subtractors, multiplexers and decoders. Sequential circuits include flip-flops, registers and counters. Signed multiplication may use Booth’s algorithm; floating-point operations require representation of sign, exponent and significand.

Instruction set and pipelining

An Instruction Set Architecture (ISA) defines the instructions and programmer-visible behaviour of a processor. RISC designs use a comparatively regular, simpler instruction set; CISC designs provide more complex instructions. Addressing modes specify how an instruction locates its operands.

Pipelining overlaps instruction stages to improve throughput. Hazards are structural (resource conflict), data (dependency) and control (branch-related). Common responses include stalling, forwarding and branch prediction.

Memory and I/O

Memory hierarchy typically moves from registers to cache, main memory and secondary storage. Cache improves average access time by exploiting locality. The curriculum also names cache replacement, NUMA, DMA and ECC. I/O methods include programmed I/O, interrupt-driven I/O and Direct Memory Access. Buses and standards include PCI, USB and SATA.

Practical / activity work: simplify logic expressions with a K-map; build and simulate a logic circuit; calculate MIPS, MFLOPS and CPI; compare processor architectures; identify pipeline hazards; demonstrate DMA conceptually.

3. CS25C07 — Object Oriented Programming (C++)

Official scope: Classes and objects; inheritance and polymorphism; pointers and runtime polymorphism; templates and exception handling; C++ streams and file I/O. The course is laboratory-integrated (3-0-4).

Class and object

A class is a user-defined type that groups data and functions. An object is an instance of a class. Encapsulation keeps data and the operations that use it together; access specifiers control visibility.

#include <iostream>
using namespace std;

class Rectangle {
    double length, width;
public:
    Rectangle(double l, double w) : length(l), width(w) {}
    double area() const { return length * width; }
};

int main() {
    Rectangle r(5, 3);
    cout << r.area();
    return 0;
}

Output: 15. The constructor initializes the object; the member function computes its area.

Constructors, destructors and members

A constructor runs when an object is created. Common forms include default, parameterized and copy constructors. A destructor runs when an object’s lifetime ends and is written with a tilde before the class name. Static data members belong to the class rather than to each individual object. Friend functions may access private/protected members when explicitly declared as friends.

Inheritance and operator overloading

Inheritance creates a derived class from a base class and supports reuse. Common forms are single, multilevel, multiple, hierarchical and hybrid inheritance. Operator overloading gives an existing operator a suitable meaning for a user-defined type; it should preserve intuitive behaviour.

class Shape {
public:
    virtual double area() const = 0;
    virtual ~Shape() = default;
};
class Square : public Shape {
    double side;
public:
    explicit Square(double s) : side(s) {}
    double area() const override { return side * side; }
};

Pointers and runtime polymorphism

A pointer stores an address. The this pointer refers to the current object. A base-class pointer can refer to a derived-class object. When a virtual function is called through such a pointer, runtime dispatch selects the derived implementation. An abstract class has at least one pure virtual function and cannot be instantiated directly.

Templates and exception handling

Function templates and class templates allow generic code to work with multiple data types. Exception handling uses try, throw and catch to handle exceptional conditions without mixing every error path into the normal algorithm.

template <typename T>
T larger(T a, T b) {
    return (a > b) ? a : b;
}

try {
    throw runtime_error("Invalid operation");
} catch (const exception& e) {
    cout << e.what();
}

Streams and file I/O

C++ streams include cin, cout, ifstream, ofstream and fstream. File operations include opening, reading, writing, closing and checking stream state. The syllabus includes formatted/unformatted I/O, file modes, sequential read/write, binary and ASCII files, and error handling.

Practical programme checklist

  1. Programs using operators, type conversion, conditional and loop statements.
  2. Inline and friend functions; constructors and destructors.
  3. Inheritance types, friend functions and operator overloading.
  4. Pointer manipulation and virtual functions.
  5. Function/class templates and exception handling.
  6. File I/O error handling and a small application using OOP features.
Common mistakes: confusing a class with an object; forgetting a virtual destructor in a polymorphic base class; dereferencing an uninitialised pointer; passing objects unnecessarily by value; and failing to check whether a file opened successfully.

4. EE25C01 — Basic Electrical and Electronics Engineering

Official scope: DC fundamentals; AC fundamentals and safety; electric machines; semiconductor devices; digital electronics; microcontrollers.

DC fundamentals

Current is the rate of flow of charge, I=Q/t. Voltage is energy transferred per unit charge. For a resistor, Ohm’s law is V=IR. Kirchhoff’s Current Law (KCL) states that algebraic current sum at a node is zero; Kirchhoff’s Voltage Law (KVL) states that algebraic voltage sum around a closed loop is zero.

Series resistors: Rₜ = R₁ + R₂ + …
Parallel resistors: 1/Rₜ = 1/R₁ + 1/R₂ + …
Voltage divider: V₁ = Vₛ × R₁/(R₁+R₂)

For ideal capacitors, C stores charge and opposes sudden voltage changes. Inductance L stores energy in a magnetic field and opposes sudden current changes.

AC fundamentals and safety

Faraday’s law relates induced emf to the rate of change of magnetic flux. A sinusoidal voltage is often written v(t)=Vₘ sin(ωt+φ). For a pure sine wave, Vᵣₘₛ=Vₘ/√2. The syllabus includes self and mutual inductance, three-phase systems, fuses and earthing.

Electrical safety: never perform live mains wiring as a learning exercise. Use isolated, low-voltage trainer circuits and instructor supervision. A fuse is an overcurrent protective device; earthing provides a low-impedance fault path to help protective devices operate.

Electric machines

Study the operating principles and applications of DC machines, transformers, three-phase induction motors, synchronous generators, single-phase induction motors, stepper motors, universal motors and BLDC motors. A transformer transfers AC power between circuits by electromagnetic induction; it does not operate as a steady-state DC transformer.

Semiconductor devices and digital electronics

A PN junction diode conducts strongly in forward bias and blocks current in reverse bias until breakdown. A Zener diode is designed to operate in reverse breakdown for voltage regulation. The curriculum includes BJT and FET transistors, timers and operational amplifiers. Digital topics include Boolean algebra, universal gates, adders, multiplexers, demultiplexers and flip-flops.

Microcontrollers

A microcontroller integrates a processor core, memory and peripherals for embedded control. Typical applications include sensor reading, motor control and automation. Learn the architecture at block-diagram level and practise through a simulator or safe development board.

How to prepare these four subjects

Linear Algebra

Practise rank, basis, eigenvalues, Gram–Schmidt, QR and least-squares sums. Verify with software after solving by hand.

Digital Principles

Draw truth tables, simplify K-maps, design adders, explain CPU datapaths, calculate performance and trace pipeline hazards.

OOP

Write and run small C++ programs daily. Explain code line by line and prepare output tracing, debugging and viva.

Electrical & Electronics

Practise circuit laws and AC calculations; draw machine/device symbols and explain operation and applications.

Practice questions

  1. Test whether a given set of three vectors in R³ is linearly independent using rank.
  2. Find eigenvalues and eigenvectors of a 2×2 matrix and determine whether it is diagonalizable.
  3. Apply Gram–Schmidt to two independent vectors in R².
  4. Simplify a four-variable Boolean function using a Karnaugh map with don't-care conditions.
  5. Explain Von Neumann and Harvard architectures with block diagrams.
  6. Calculate CPU execution time from instruction count, CPI and clock rate.
  7. Write a C++ program using a class, constructor and member function to model a bank account.
  8. Demonstrate runtime polymorphism using a base pointer and virtual function.
  9. Explain KCL and KVL and solve a two-loop resistive circuit.
  10. Compare a PN junction diode and Zener diode with suitable applications.
Answer-writing format: definition → labelled diagram / equation → stepwise explanation or derivation → worked example → application. For programming questions, include algorithm, code, sample input/output and explanation.
