TOPIC 1

Problem Solving and Introduction to C

1.1 What is programming?

Programming is the process of designing a sequence of instructions that makes a computer perform a required task. A programming solution should be correct, understandable, efficient enough for its purpose and testable.

C is a general-purpose, procedural programming language. It provides operators, control statements, functions, arrays, pointers and structures. It is widely used in system software, embedded systems and performance-sensitive applications.

1.2 Problem-solving cycle

  1. Problem definition: state exactly what is required.
  2. Input and output analysis: identify data supplied, results required and constraints.
  3. Algorithm design: arrange the solution as finite, unambiguous steps.
  4. Flowchart / pseudocode: represent the logic before coding.
  5. Coding: translate the algorithm into C statements.
  6. Compilation: translate source code and report syntax/type errors.
  7. Execution and testing: run the program with selected test cases.
  8. Debugging and documentation: correct errors and record how the program works.

1.3 Problem Analysis Chart (PAC)

A problem analysis chart organises the problem before programming. A useful PAC records the problem, inputs, outputs, processing/formula, assumptions and constraints. It prevents a common mistake: starting to code before understanding what information is available and what result is expected.

Worked PAC: area of a circle

ProblemFind the area of a circle.
InputRadius r (a non-negative real number).
OutputArea A.
ProcessingA = π × r × r.
AssumptionRadius is entered in the required unit; output is in the corresponding square unit.

1.4 Algorithm

An algorithm is a finite sequence of clear steps for solving a problem. A good algorithm has clearly defined inputs and outputs, definite instructions, a finite number of steps and steps that can be carried out.

Algorithm: find the larger of two numbers

  1. Start.
  2. Read A and B.
  3. If A is greater than B, display A as the larger number.
  4. Otherwise, if B is greater than A, display B.
  5. Otherwise, display that both values are equal.
  6. Stop.

1.6 Pseudocode

Pseudocode describes the logic in a structured, language-independent form. It is not compiled. Use words such as READ, IF, ELSE, WHILE, DISPLAY and END to make the steps easy to follow.

BEGIN
    READ radius
    area ← 3.14159 × radius × radius
    DISPLAY area
END

1.7 Structure of a C program

#include 

int main(void)
{
    int a = 10;
    int b = 20;
    int sum = a + b;

    printf("Sum = %d\n", sum);
    return 0;
}

Explanation: #include is a preprocessor directive that makes declarations from a header available. main() is the program entry point in a hosted C program. Braces enclose a block. Statements normally end with a semicolon. return 0; indicates successful termination to the host environment.

1.8 Compilation and execution

  1. Source code: programmer writes the C source file, for example sum.c.
  2. Preprocessing: directives such as header inclusion and macros are handled.
  3. Compilation: source code is translated and checked.
  4. Assembly and linking: object code is produced and combined with required library code.
  5. Execution: the resulting executable is run with test data.
gcc -std=c11 -Wall -Wextra sum.c -o sum
./sum

1.9 Comments, indentation and errors

Comments explain the purpose of code and are ignored by the compiler. A single-line comment begins with //; a block comment begins with /* and ends with */. Indentation does not define blocks in C, but consistent indentation makes nested logic readable.

1.10 Data types, constants and variables

A data type determines the kind of value a variable can represent and the operations that are meaningful for it. The size of a type can depend on the implementation; use sizeof rather than assuming every platform has identical sizes.

1.11 Identifiers and reserved words

An identifier names a variable, function, structure or other program element. It may contain letters, digits and underscores, but cannot begin with a digit. C is case-sensitive. A reserved keyword such as int, return, if or while cannot be used as an ordinary identifier.

TOPIC 2

Control Structures

Control structures decide which statements execute and how often. C provides selection statements, iteration statements and jump statements.

2.1 if statement

if (temperature > 40) {
    printf("High temperature\n");
}

The statement block executes only when the condition is non-zero (true).

2.2 if–else statement

if (number % 2 == 0) {
    printf("Even\n");
} else {
    printf("Odd\n");
}

2.3 Nested if and else-if ladder

A nested if places one decision inside another. An else-if ladder is useful when several mutually exclusive ranges or categories must be checked. Arrange range conditions carefully from the highest or lowest boundary as appropriate.

if (mark < 0 || mark > 100) {
    printf("Invalid mark\n");
} else if (mark >= 90) {
    printf("Grade O\n");
} else if (mark >= 80) {
    printf("Grade A+\n");
} else if (mark >= 70) {
    printf("Grade A\n");
} else if (mark >= 60) {
    printf("Grade B+\n");
} else if (mark >= 50) {
    printf("Grade B\n");
} else {
    printf("RA / Fail\n");
}

2.4 switch-case

The switch statement selects a branch based on an integer-type expression (including enumerated types). Each case label must be a constant expression. break prevents execution from continuing into the next case.

int choice = 2;

switch (choice) {
    case 1:
        printf("Addition\n");
        break;
    case 2:
        printf("Subtraction\n");
        break;
    case 3:
        printf("Multiplication\n");
        break;
    default:
        printf("Invalid choice\n");
}

2.5 while loop

A while loop checks its condition before executing the body. It may execute zero times if the condition is initially false.

int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;
}

2.6 do–while loop

A do–while loop executes the body first and checks the condition afterwards. Therefore, the body executes at least once.

int choice;
do {
    printf("1. Continue  0. Exit: ");
    scanf("%d", &choice);
} while (choice != 0);

2.7 for loop

A for loop combines initialisation, condition checking and updating in one statement. It is commonly used when the number of iterations is known.

int i;
for (i = 1; i <= 10; i++) {
    printf("%d\n", i);
}

2.8 Nested loops

A nested loop is a loop inside another loop. The inner loop completes its iterations for each iteration of the outer loop. Nested loops are useful for tables, matrices and pattern generation.

int i, j;
for (i = 1; i <= 3; i++) {
    for (j = 1; j <= 4; j++) {
        printf("%d ", i * j);
    }
    printf("\n");
}

2.9 Jump statements

StatementActionTypical use
breakTerminates the nearest loop or switch.Exit a search loop after finding a match.
continueSkips to the next iteration of the nearest loop.Skip invalid or unwanted values.
returnEnds the current function and optionally returns a value.Return result or status from a function.

Remember for exams: while checks first; do–while checks after the body; for combines loop control expressions. In a switch, explain the purpose of break and default.
TOPIC 3

Functions and Modular Programming

3.1 Why functions are used

A function is a named block of statements that performs a particular task. Dividing a large program into functions improves readability, reuse, testing and maintenance. Each function should have a clear responsibility.

3.2 Declaration, definition and call

#include 

/* Function declaration / prototype */
int add(int x, int y);

int main(void)
{
    int result = add(12, 8);  /* function call */
    printf("Sum = %d\n", result);
    return 0;
}

/* Function definition */
int add(int x, int y)
{
    return x + y;
}
StageMeaning
Declaration / prototypeInforms the compiler of function name, return type and parameter types.
DefinitionProvides the actual body of the function.
CallTransfers control to the function with supplied arguments.

3.3 Parameters and return types

Parameters receive information from the calling function. A function may return a value of its declared type. Use void when no value is returned or when a function takes no parameters, as appropriate.

void displayMessage(void)
{
    printf("Welcome to C programming\n");
}

double rectangleArea(double length, double breadth)
{
    return length * breadth;
}

3.4 Call by value

In C, function arguments are passed by value. The parameter receives a copy of the argument value. Changing the parameter does not change the caller's original variable.

void changeValue(int x)
{
    x = 100;
}

int main(void)
{
    int a = 10;
    changeValue(a);
    printf("%d\n", a);  /* still 10 */
    return 0;
}

3.5 Modifying caller data using pointers

What is commonly called “call by reference” in introductory courses is achieved in C by passing an address (a pointer) by value. The function can use that pointer to modify the object at the supplied address.

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void)
{
    int x = 5, y = 9;
    swap(&x, &y);
    printf("x=%d y=%d\n", x, y);
    return 0;
}
Technical accuracy: C does not have a separate reference-parameter mechanism like C++. Even in the pointer example, the pointer itself is passed by value; dereferencing it allows the function to modify the caller's object.

3.6 Recursion

Recursion is a technique in which a function calls itself to solve a smaller version of a problem. Every correct recursive function needs a base case and a recursive case.

long factorial(int n)
{
    if (n < 0) {
        return -1;            /* invalid input indicator */
    }
    if (n == 0 || n == 1) {
        return 1;             /* base case */
    }
    return n * factorial(n - 1);
}

For a non-negative integer n, factorial is n! = n × (n−1) × ... × 2 × 1, and 0! = 1. In practical programs, also consider the range of the selected integer type to avoid overflow.

3.7 Scope and lifetime of variables

CategoryScope / lifetime
Block scope local variableVisible from its declaration to the end of the enclosing block; ordinary automatic local objects exist while the block is active.
File scope objectDeclared outside functions; name is visible from its declaration to the end of the translation unit, subject to linkage rules.
Static local variableBlock scope, but storage duration lasts for the entire program; retains its value between function calls.
Function parameterScope is the function definition; its lifetime is associated with the function call.
void counter(void)
{
    static int count = 0;
    count++;
    printf("%d\n", count);
}

Calling counter() repeatedly prints 1, then 2, then 3 because the static local variable retains its stored value.

3.8 Header files and modular programming

A header file commonly contains declarations, macros, type definitions and function prototypes shared by source files. Modular programming divides a program into separately understandable and testable components. Use include guards to prevent repeated inclusion.

/* calculator.h */
#ifndef CALCULATOR_H
#define CALCULATOR_H

int add(int a, int b);

#endif
TOPIC 4

Arrays, Strings and Pointers

4.1 One-dimensional arrays

An array stores a fixed number of elements of the same type in contiguous memory locations. Indexing starts at zero. For an array of n elements, valid indices are 0 through n−1.

#include 

int main(void)
{
    int marks[5] = {78, 82, 69, 91, 85};
    int i, total = 0;

    for (i = 0; i < 5; i++) {
        total += marks[i];
    }

    printf("Total = %d\n", total);
    printf("Average = %.2f\n", total / 5.0);
    return 0;
}

4.2 Array traversal and operations

Traversal means visiting each element in sequence. Common operations include reading, displaying, summing, finding maximum/minimum, searching, copying and sorting. Always ensure that an index stays within the array bounds; C does not automatically check array bounds.

Worked example: find maximum in an array

int a[5] = {14, 8, 32, 19, 25};
int max = a[0];
int i;

for (i = 1; i < 5; i++) {
    if (a[i] > max) {
        max = a[i];
    }
}
printf("Maximum = %d\n", max);

Logic: Assume the first element is the maximum. Compare every remaining element and update max whenever a larger value is found.

4.3 Multi-dimensional arrays

A two-dimensional array is commonly used to represent a table or matrix. C stores array elements in row-major order.

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

int i, j;
for (i = 0; i < 2; i++) {
    for (j = 0; j < 3; j++) {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}

4.4 Strings in C

C does not have a separate built-in string data type. A string is conventionally stored as an array of characters terminated by the null character '\\0'. The null character marks the end of the string and must have space in the array.

char name[20] = "Anitha";
printf("%s\n", name);

Use fgets() to read a line safely into a fixed-size character array. Avoid unbounded scanf("%s", ...) when input length is not controlled.

char name[40];

printf("Enter your name: ");
if (fgets(name, sizeof name, stdin) != NULL) {
    printf("Hello, %s", name);
}

4.5 String library functions

Include <string.h> to use common string functions. These functions expect correctly terminated strings and sufficient destination space.

FunctionPurposeExample use
strlen(s)Returns string length excluding the null terminator.strlen(name)
strcpy(d,s)Copies source string to destination.Destination must have enough space.
strcat(d,s)Appends source string to destination.Destination must have enough remaining space.
strcmp(a,b)Compares two strings.Returns negative, zero or positive result.

4.6 Pointer basics

A pointer is an object that stores the address of another object or function. The address-of operator & obtains an object's address. The indirection operator * accesses the object pointed to.

int value = 25;
int *ptr = &value;

printf("Value = %d\n", value);
printf("Address = %p\n", (void *)ptr);
printf("Value through pointer = %d\n", *ptr);

In this example, ptr stores the address of value, and *ptr refers to the value stored at that address.

4.7 Pointer arithmetic

When a pointer points to an element of an array, adding one advances it to the next element of that type. The address change is scaled by the size of the pointed-to type. Pointer arithmetic is defined within an array object and one position past its end; dereferencing the one-past pointer is not valid.

int a[3] = {10, 20, 30};
int *p = a;

printf("%d\n", *p);       /* 10 */
printf("%d\n", *(p + 1)); /* 20 */
printf("%d\n", *(p + 2)); /* 30 */

4.8 Relationship between pointers and arrays

In most expressions, an array expression is converted to a pointer to its first element. This is why a[i] is equivalent to *(a + i). However, an array and a pointer are not identical objects: an array has its own storage and fixed extent, while a pointer is a separate variable that can store an address.

4.9 Pointer to function

A function pointer stores the address of a function with a compatible signature. It is useful for callbacks and selecting an operation at runtime.

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int (*operation)(int, int) = add;
    printf("%d\n", operation(4, 6));
    return 0;
}

4.10 Dynamic memory allocation

Dynamic memory is requested at runtime from the heap using functions declared in <stdlib.h>. The programmer must check allocation success and release allocated memory with free() when it is no longer needed.

FunctionPurpose
malloc(size)Allocates a block of uninitialised memory.
calloc(n,size)Allocates space for n elements and sets all bytes to zero.
realloc(ptr,size)Changes the size of an existing allocated block.
free(ptr)Releases a previously allocated block.
#include 
#include 

int main(void)
{
    size_t n = 5;
    int *a = malloc(n * sizeof *a);

    if (a == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    for (size_t i = 0; i < n; i++) {
        a[i] = (int)(i + 1) * 10;
    }

    for (size_t i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }

    free(a);
    a = NULL;
    return 0;
}
Pointer safety: Never dereference an uninitialised, null, freed or out-of-bounds pointer. Do not access memory after it has been freed. Allocate enough space, check the result and release memory exactly once.
TOPIC 5

Structures, Unions and Enumerations

5.1 Structure

A structure is a user-defined type that groups related variables, possibly of different data types, under one name. Each member has its own storage within the structure object.

struct Student {
    int rollNo;
    char name[30];
    float mark;
};

int main(void)
{
    struct Student s1 = {101, "Kavi", 87.5f};
    printf("%d %s %.1f\n", s1.rollNo, s1.name, s1.mark);
    return 0;
}

5.2 Accessing structure members

Use the dot operator (.) with a structure object. Use the arrow operator (->) with a pointer to a structure.

struct Student s = {102, "Arun", 91.0f};
struct Student *p = &s;

printf("%s\n", s.name);  /* dot operator */
printf("%.1f\n", p->mark); /* arrow operator */

5.3 Array of structures

An array of structures stores multiple records of the same structure type. It is useful for student details, employee records, inventory and similar data.

struct Student {
    int rollNo;
    char name[20];
    float mark;
};

int main(void)
{
    struct Student s[2] = {
        {1, "Mala", 82.0f},
        {2, "Ravi", 76.5f}
    };

    for (int i = 0; i < 2; i++) {
        printf("%d %s %.1f\n",
               s[i].rollNo, s[i].name, s[i].mark);
    }
    return 0;
}

5.4 Pointer to structure

A pointer can store the address of a structure. The arrow operator makes member access concise. Structure pointers are useful when passing large structures to functions without copying the whole object.

5.5 Union

A union is a user-defined type in which all members share the same storage area. The size of a union is sufficient for its largest member, subject to alignment and implementation requirements. At a given time, the value stored should be interpreted using the member that was most recently written, with limited standard-defined exceptions.

union Data {
    int i;
    float f;
    char ch;
};

int main(void)
{
    union Data d;
    d.i = 25;
    printf("%d\n", d.i);

    d.f = 4.5f; /* overwrites the shared storage */
    printf("%.1f\n", d.f);
    return 0;
}

5.6 Structure versus union

StructureUnion
Each member has separate storage within the object.Members share the same storage.
Members can hold values simultaneously.Normally one member's value is active at a time.
Size is at least enough for all members plus any padding.Size is at least enough for the largest member plus alignment.
Used for records containing multiple related fields.Used when a value may be represented in one of several alternative forms.

5.7 Enumerations

An enumeration defines a type consisting of named integer constants. It improves readability when a variable should take one of a small set of named states.

enum Day {
    MONDAY = 1, TUESDAY, WEDNESDAY,
    THURSDAY, FRIDAY, SATURDAY, SUNDAY
};

enum Day today = WEDNESDAY;
printf("%d\n", today);
TOPIC 6

File Operations

6.1 Why files are needed

Variables in ordinary program memory do not automatically preserve their values after the program terminates. Files provide persistent storage for records, reports and data that must be used again later.

6.2 File pointer and opening a file

C uses a FILE object, declared through <stdio.h>, to manage a stream. A FILE * is commonly called a file pointer. The fopen() function opens a file and returns a pointer, or NULL if opening fails.

ModeMeaning

w+Open for reading and writing; create or truncate.
a+Open for reading and appending; create if absent.
Binary formsAdd b, e.g. rb, wb, ab.

6.3 Writing to a text file

#include 

int main(void)
{
    FILE *fp = fopen("result.txt", "w");
    if (fp == NULL) {
        perror("Cannot open file");
        return 1;
    }

    fprintf(fp, "ACADRIX C programming notes\n");
    fprintf(fp, "File handling example\n");

    if (fclose(fp) == EOF) {
        perror("Error closing file");
        return 1;
    }
    return 0;
}

6.4 Reading from a text file

#include 

int main(void)
{
    FILE *fp = fopen("result.txt", "r");
    int ch;

    if (fp == NULL) {
        perror("Cannot open file");
        return 1;
    }

    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch);
    }

    fclose(fp);
    return 0;
}

Use an int variable to store the result of fgetc() so it can represent every unsigned-char value and the special EOF value.

6.6 Text file versus binary file

Text fileStores data as character representations. Easier for humans to inspect and exchange, but conversion/parsing may be required.
Binary fileStores data as bytes. Often compact and efficient for program-specific records, but may depend on data layout, type sizes and platform representation.

6.7 Error handling

Check whether fopen() returned NULL, whether read/write functions completed the expected operation, and whether fclose() succeeded. Use perror() or strerror() where suitable to report errors. Do not assume that a file exists or that every disk operation succeeds.

}

Exam point: A header normally declares the interface; a source file provides the function definition. Include guards prevent the same header contents from being processed repeatedly in one translation unit.

HOW TO PRESENT IN THE EXAM

Answer-writing method for C programming

  1. Define the concept: give a precise meaning before explaining it.
  2. Explain syntax: show the general form of the statement or function.
  3. Draw a flowchart / write an algorithm: when the question is problem-based, show the logic before code.
  4. Write a complete program: include required header files, main function, declarations, input, processing, output and return statement.
  5. Explain important lines: especially conditions, loop updates, function calls, pointer expressions and file modes.
  6. Show sample output: use test data that demonstrates the result.
  7. Check edge cases: empty strings, zero values, invalid input, array limits, allocation failure and file-open failure.

Frequent mistakes to avoid

  • Using = instead of == in a comparison.
  • Forgetting & for ordinary variables in scanf().
  • Using the wrong format specifier for the variable type.
  • Accessing an array outside its valid index range.
  • Forgetting the null terminator in a character array used as a string.
  • Dereferencing an uninitialised or null pointer.
  • Forgetting to check memory allocation and to call free().
  • Not checking whether a file opened successfully.
  • Forgetting break in a switch when fall-through is not intended.
Programming is learned by writing programs. Read the explanation, close the notes, write the program from memory, compile it, test it with more than one input, and then explain why each statement is needed.
