ANNA UNIVERSITY · R-2025 · MULTI-DEPARTMENT

Common First-Year Resource Library

One maintained set of study resources for Semester I and Semester II courses shared by multiple engineering programmes. Department pages should link here rather than duplicate the same notes.

Semester I + IIShared resource modelCourse-code awareUpdated 7 Nov 2026
Sharing rule: Reuse a notes page only when the official curriculum confirms the same course code and matching syllabus. Similar course titles do not automatically mean identical syllabi. If a department has a different course code, unit list, practical component or assessment, link to a department-specific version or label the shared page as supplementary only.

Subjects that must remain department-specific

ExampleWhy it should not be copied blindly
Semester II mathematicsCSE/Civil use Linear Algebra (MA25C02) in the checked examples, while EEE/EIE use Transforms and its Applications (MA25C03).
Semester II physicsCourse titles are discipline-labelled: Applied Physics (CSIE) – II, Applied Physics (CE) – II and Applied Physics (EE) – II.
Programming / computingSemester I examples include C, Python or Essentials of Computing depending on programme. Semester II CSE computing subjects are not common to all branches.
Department introductory coursesMechanical, Civil, EEE, EIE and other programmes have different discipline introductory courses.
Engineering drawing / mechanics / circuitsThese are included differently by programme and semester; use the matching department syllabus.

How ACADRIX will use this library

  1. Maintain one master notes page for each genuinely shared subject.
  2. Record the official course code, title, semester and syllabus source in the resource catalogue.
  3. Compare each department curriculum before adding a link.
  4. Show a clear note when the same subject title has a different code or syllabus.
  5. Keep branch-specific notes separate and avoid copying the same content into multiple files.
Coverage note: This is an initial common-resource map based on the R-2025 curricula checked for CSE, Civil, EEE, EIE, Aeronautical Engineering and Computer Science and Business Systems. It is not a claim that every listed course is identical across every one of the 53 programmes. More programme PDFs must be checked before assigning common links across all departments.
