Course approach and outcomes

Calculus studies how quantities change and how small contributions accumulate. Differentiation measures instantaneous rate of change and helps analyse maxima, minima and graph shape. Integration accumulates quantities and is used to calculate area, volume, arc length and net change. Partial derivatives extend these ideas to functions depending on more than one independent variable.

Recommended method for every numerical problem: identify the function and variables, write the relevant formula, substitute carefully, show intermediate algebra, state units where applicable, and interpret the result.

Official course scope: differential calculus; functions of several variables; integral calculus; and multiple integrals. The curriculum also expects visualisation and use of open-source computational tools, including solving application-oriented and GATE-style problems.

1. Functions and graphs

1.1 Definition

A function is a rule that assigns exactly one output to each allowed input. If (y=f(x)), then (x) is the independent variable and (y) is the dependent variable. The domain is the set of permitted inputs; the range is the set of resulting outputs.

Example: (f(x)=\sqrt{9-x^2}). For real outputs, (9-x^2\geq0), so (-3\leq x\leq3). The domain is ([-3,3]) and the range is ([0,3]).

1.2 Common function families

1.3 Transformations

  • \(f(x)+k\): shift graph vertically upward by k (downward if k is negative).
  • \(f(x-h)\): shift graph horizontally right by h.
  • \(-f(x)\): reflect across the x-axis.
  • \(f(-x)\): reflect across the y-axis.
  • \(af(x)\): vertical scaling by factor |a|.

For a new function formed from old functions, identify the transformation before plotting. This makes graph sketching quicker and reduces sign errors.

2. Limits and continuity

2.1 Meaning of a limit

\(\lim_{x\to a}f(x)=L\) means that values of f(x) can be made arbitrarily close to L by taking x sufficiently close to a (but not necessarily equal to a). A limit concerns nearby behaviour, not just the value at the point.

2.2 Basic limit laws

\(\lim(f\pm g)=\lim f\pm\lim g\)
\(\lim(fg)=(\lim f)(\lim g)\)
\(\lim(f/g)=(\lim f)/(\lim g)\), provided the denominator limit is non-zero.

For polynomials, direct substitution is valid. For a rational expression that gives 0/0, factorise and cancel common factors where valid, or use a suitable identity.

Worked example: Evaluate \(\lim_{x\to2}(x^2-4)/(x-2)\). Factorise: \((x-2)(x+2)/(x-2)=x+2\), for x ≠ 2. Therefore the limit is \(4\).

2.3 Standard trigonometric limits

\(\lim_{x\to0}\frac{\sin x}{x}=1\) (x in radians)
\(\lim_{x\to0}\frac{1-\cos x}{x^2}=\frac12\)

These standard results are used after rewriting an expression into a matching form. Ensure angles are in radians.

2.4 One-sided limits

The left-hand limit approaches a from values smaller than a; the right-hand limit approaches from values greater than a. The two-sided limit exists only if both one-sided limits exist and are equal.

2.5 Continuity

A function is continuous at x=a when (i) f(a) is defined, (ii) the limit as x approaches a exists, and (iii) the limit equals f(a).

Example: Define \(f(x)=(x^2-1)/(x-1)\) for x ≠ 1 and f(1)=2. Since the expression simplifies to x+1 for x ≠ 1, its limit at 1 is 2, equal to f(1). Thus it is continuous at 1.

2.6 Limits at infinity

For rational functions, compare the highest powers of x in numerator and denominator. If degrees are equal, the limit is the ratio of leading coefficients. If numerator degree is smaller, the limit is 0. If numerator degree is larger, the expression generally grows without bound or has no finite limit; inspect signs and degrees.

3. Derivatives

3.1 Derivative from first principles

The derivative is the limiting rate of change of a function with respect to its input.

\(f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}\)

Geometrically, it is the slope of the tangent to the curve. Physically, if position is s(t), then velocity is ds/dt and acceleration is d²s/dt².

First-principles example: For f(x)=x², \(f(x+h)=(x+h)^2\). The difference quotient is \((2xh+h^2)/h=2x+h\). Taking h→0 gives \(f'(x)=2x\).

3.3 Rules

Sum: \((u+v)'=u'+v'\)   Product: \((uv)'=u'v+uv'\)
Quotient: \((u/v)'=(vu'-uv')/v^2\)
Chain rule: \(\frac{dy}{dx}=\frac{dy}{du}\frac{du}{dx}\)
Example — product rule: Differentiate y=x² sin x. Let u=x², v=sin x. Then y'=2x sin x+x² cos x.
Example — chain rule: y=(3x²+1)^5. Let u=3x²+1. Then dy/dx=5u⁴·6x=30x(3x²+1)^4.

3.4 Implicit differentiation

When x and y are related by an equation rather than y being isolated, differentiate both sides with respect to x. Every derivative of a y-term must include dy/dx.

Example: x²+y²=25. Differentiating gives 2x+2y(dy/dx)=0, hence \(dy/dx=-x/y\).

4. Mean value theorem

4.1 Rolle's theorem

If f is continuous on [a,b], differentiable on (a,b), and f(a)=f(b), then at least one point c in (a,b) has f'(c)=0. The tangent is horizontal at that point.

4.2 Lagrange mean value theorem

If f is continuous on [a,b] and differentiable on (a,b), then at least one c in (a,b) satisfies:

\(f'(c)=\frac{f(b)-f(a)}{b-a}\)

The instantaneous slope at c equals the average slope over the interval.

Example: For f(x)=x² on [1,3], average slope = (9−1)/(3−1)=4. Since f'(x)=2x, set 2c=4, giving c=2, which lies in (1,3).
Do not omit conditions: State continuity on the closed interval and differentiability on the open interval before applying the theorem.

5. Effect of derivatives on graph shape

  • If f'(x)>0 on an interval, f is increasing there.
  • If f'(x)<0, f is decreasing there.
  • If f''(x)>0, the graph is concave upward.
  • If f''(x)<0, the graph is concave downward.
  • A point where concavity changes is an inflection point; verify the change rather than relying only on f''=0.

5.1 Critical points

A critical number occurs where f'(x)=0 or where f'(x) does not exist, provided the function itself is defined there. Critical points are candidates for local maxima/minima, not automatically extrema.

5.2 First derivative test

Check the sign of f' immediately to the left and right of a critical point. A change + to − indicates a local maximum; − to + indicates a local minimum; no sign change means no local extremum.

5.3 Second derivative test

If f'(c)=0 and f''(c)>0, f has a local minimum at c. If f''(c)<0, it has a local maximum. If f''(c)=0, the test is inconclusive.

6. Maxima and minima of a single-variable function

An absolute maximum is the greatest function value on the entire domain under consideration; an absolute minimum is the least. A local extremum is greatest or least only in a neighbourhood of the point.

6.1 Procedure for a closed interval

  1. Find critical points inside the interval.
  2. Evaluate f at every critical point.
  3. Evaluate f at both endpoints.
  4. Compare all values; the largest is the absolute maximum and the smallest is the absolute minimum.
Worked example: Find absolute extrema of f(x)=x²−4x+1 on [0,5]. f'(x)=2x−4=0 gives x=2. Evaluate: f(0)=1, f(2)=−3, f(5)=6. Therefore absolute minimum is −3 at x=2 and absolute maximum is 6 at x=5.

6.2 Engineering optimisation model

Translate the design question into an objective function and constraints. For example, a manufacturer may minimise material cost while maintaining a required volume. Clearly define the design variable, allowable range and units. A mathematical optimum is useful only if it satisfies the physical constraints.

7. Functions of several variables and partial derivatives

A function of two variables is written z=f(x,y). A partial derivative measures the rate of change with respect to one variable while holding the other independent variables constant.

\(f_x=\frac{\partial f}{\partial x},\quad f_y=\frac{\partial f}{\partial y}\)
Example: f(x,y)=x²y+3xy². Holding y constant, \(f_x=2xy+3y²\). Holding x constant, \(f_y=x²+6xy\).

7.1 Higher-order partial derivatives

Differentiate a partial derivative again. For example, fxx means differentiate fx with respect to x; fxy means differentiate fx with respect to y. If the relevant second derivatives are continuous near a point, mixed partial derivatives are equal: fxy=fyx.

7.2 Geometric meaning

For z=f(x,y), fixing y gives a cross-section curve in the x direction; its slope is fx. Fixing x gives a cross-section in the y direction; its slope is fy. The gradient vector points in the direction of steepest increase.

\(\nabla f=\left(f_x,f_y\right)\)

8. Chain rule and total derivative

8.1 Chain rule for dependent variables

If z=f(x,y), where x=x(t) and y=y(t), then z changes with t through both x and y:

\(\frac{dz}{dt}=\frac{\partial z}{\partial x}\frac{dx}{dt}+\frac{\partial z}{\partial y}\frac{dy}{dt}\)
Example: z=x²+y², x=2t, y=3t. Then dz/dt=2x(2)+2y(3)=4x+6y. Substituting x=2t, y=3t gives dz/dt=26t.

8.2 Total differential

\(dz=f_x\,dx+f_y\,dy\)

For small changes, dz estimates the corresponding change in z. It is used in sensitivity analysis and error estimation. The approximation is most useful when dx and dy are small.

8.3 Engineering interpretation

If a measured output depends on temperature and pressure, the partial derivatives indicate how sensitive the output is to each variable when the other is held fixed. The total differential combines the effects of small changes in both.

9. Maxima and minima of functions of two variables

9.1 Stationary points

For an interior stationary point, solve both equations fx=0 and fy=0 simultaneously. These points are candidates for local maxima, local minima or saddle points.

9.2 Second derivative test

At a stationary point, calculate:

\(D=f_{xx}f_{yy}-(f_{xy})^2\)
ConditionConclusion
D > 0 and fxx > 0Local minimum.
D > 0 and fxx < 0Local maximum.
D < 0Saddle point.
D = 0Test is inconclusive.
Example: f=x²+y²−4x−6y. fx=2x−4=0 gives x=2; fy=2y−6=0 gives y=3. fxx=2, fyy=2, fxy=0, so D=4>0 and fxx>0. Hence (2,3) is a local minimum. The value is f(2,3)=−13.
Important: The second derivative test classifies an interior stationary point. For a constrained or closed region, also examine the boundary and endpoints.

10. Method of Lagrange multipliers

Use Lagrange multipliers to find extrema of f(x,y) subject to a constraint g(x,y)=c, when the required differentiability and regularity conditions hold.

\(\nabla f=\lambda\nabla g,\quad g(x,y)=c\)

In two variables, solve fx=λgx, fy=λgy and the constraint equation together.

Worked example: Find extrema of f(x,y)=xy subject to x²+y²=1. Equations: y=2λx and x=2λy. For non-zero x,y, these imply x²=y². With x²+y²=1, candidates are (1/√2,1/√2), (−1/√2,−1/√2), (1/√2,−1/√2), (−1/√2,1/√2). The product is +1/2 at the same-sign pairs (maximum) and −1/2 at opposite-sign pairs (minimum).

10.1 Practical procedure

  1. Write the objective f.
  2. Write the constraint g=c.
  3. Calculate both gradients.
  4. Set ∇f=λ∇g.
  5. Solve the simultaneous equations with the constraint.
  6. Evaluate f at all feasible candidates and compare.

11. Integral calculus

11.1 Antiderivative and indefinite integral

An antiderivative F of f satisfies F'(x)=f(x). The indefinite integral represents the family of antiderivatives:

\(\int f(x)\,dx=F(x)+C\)

The constant C is necessary because the derivative of any constant is zero.

11.2 Basic integration formulae

IntegrandIntegral

\(\cos x\)\(\sin x+C\)

11.3 Substitution

Use substitution when the integrand contains a function and (a multiple of) its derivative. Put u=g(x), so du=g'(x)dx.

Example: \(\int 2x\cos(x^2)dx\). Let u=x², du=2x dx. Integral becomes ∫cos u du=sin u+C=sin(x²)+C.

11.4 Integration by parts

\(\int u\,dv=uv-\int v\,du\)
Example: ∫x eˣ dx. Choose u=x, dv=eˣdx; then du=dx and v=eˣ. Result = xeˣ−∫eˣdx=eˣ(x−1)+C.

11.5 Definite integral

A definite integral gives the signed accumulated quantity over an interval:

\(\int_a^b f(x)dx=F(b)-F(a)\)

Geometrically, area above the x-axis contributes positively and area below contributes negatively. For total geometric area, split at any x-intercepts and use absolute values as appropriate.

11.6 Fundamental theorem of calculus

If f is continuous on [a,b] and F'=f, then ∫aᵇ f(x)dx=F(b)−F(a). Also, if G(x)=∫aˣ f(t)dt, then G'(x)=f(x) at points of continuity. These statements connect differentiation and integration.

11.7 Net change theorem

The integral of a rate of change over an interval equals the net change in the quantity. If v(t) is velocity, ∫aᵇv(t)dt gives displacement, not necessarily total distance. Total distance is ∫aᵇ|v(t)|dt.

12. Improper integrals

An integral is improper when an integration limit is infinite or the integrand becomes unbounded at an endpoint or an interior point. Define it using a limit.

\(\int_a^\infty f(x)dx=\lim_{b\to\infty}\int_a^b f(x)dx\)
Example: Evaluate ∫₁∞ 1/x² dx. Write limit B→∞ of [−1/x]₁ᴮ = lim(1−1/B)=1. Hence it converges to 1.
Comparison example: ∫₁∞ 1/x dx = lim B→∞ ln B, which grows without bound. Hence it diverges.

12.1 Convergence

An improper integral converges if its defining limit exists and is finite; otherwise it diverges. For an interior singularity c, split the integral at c and evaluate the two one-sided improper integrals separately. Both must converge.

13. Arc length, area and surface of revolution

13.1 Area between a curve and the x-axis

\(A=\int_a^b |f(x)|dx\)

If f(x) is non-negative on the interval, the absolute value is unnecessary. If the curve crosses the axis, split the interval at the crossing points.

13.2 Area between two curves

\(A=\int_a^b [f_{top}(x)-f_{bottom}(x)]dx\)

Find intersection points first. Confirm which curve is upper on each subinterval; if the order changes, split the integral.

13.3 Arc length

For a differentiable curve y=f(x) on [a,b], the arc length is:

\(L=\int_a^b\sqrt{1+[f'(x)]^2}\,dx\)
Example: For y=3x on 0≤x≤2, y'=3. Thus L=∫₀²√10 dx=2√10.

13.4 Surface area of revolution

When y=f(x)≥0 is revolved about the x-axis, the surface area is:

\(S=2\pi\int_a^b y\sqrt{1+(dy/dx)^2}\,dx\)

For revolution about the y-axis using x as a function of y, the corresponding formula is \(S=2\pi\int_c^d x\sqrt{1+(dx/dy)^2}\,dy\). Sketch the curve and axis before selecting the formula. Ensure the radius is measured perpendicular to the axis of rotation.

14. Multiple integrals — double integrals

14.1 Meaning

A double integral accumulates a function over a two-dimensional region. If f(x,y) represents a surface height or density, the integral combines its contribution over the region R.

\(\iint_R f(x,y)\,dA\)

For a rectangular region a≤x≤b, c≤y≤d, an iterated form is ∫aᵇ∫cᵈ f(x,y)dy dx, provided the relevant integrability conditions are satisfied.

14.2 Fubini's theorem and iterated integration

For suitable continuous functions on a rectangle, the double integral can be evaluated as an iterated integral in either order:

\(\int_a^b\int_c^d f(x,y)\,dy\,dx=\int_c^d\int_a^b f(x,y)\,dx\,dy\)

Integrate with respect to the inner variable first, treating the other variable as a constant. Then apply the outer limits.

Worked example: Evaluate ∫₀¹∫₀²(x+2y)dy dx. Inner integral = [xy+y²]₀²=2x+4. Outer integral = ∫₀¹(2x+4)dx=[x²+4x]₀¹=5.

14.3 Non-rectangular regions

For a region described by g₁(x)≤y≤g₂(x), with a≤x≤b, write ∫aᵇ∫g₁(x)g₂(x) f(x,y)dy dx. Alternatively, describe the region using x-bounds that depend on y. Draw the region before setting the limits.

14.4 Change of order of integration

  1. Read the original limits and sketch the region.
  2. Mark the boundary curves and intersection points.
  3. Choose the opposite order and express the new outer interval.
  4. Express the inner limits from the lower to upper boundary in the new direction.
  5. If the boundary description changes, split the region into simpler pieces.
Example region: 0≤x≤1, 0≤y≤x. Reversing order gives 0≤y≤1 and y≤x≤1. Thus ∫₀¹∫₀ˣ f(x,y)dy dx = ∫₀¹∫ᵧ¹ f(x,y)dx dy.

14.5 Polar coordinates

Use polar coordinates for circular or radial regions:

\(x=r\cos\theta,\quad y=r\sin\theta,\quad dA=r\,dr\,d\theta\)

The extra factor r is the Jacobian. For a disk of radius a, the limits are 0≤r≤a and 0≤θ≤2π.

Example: Find the area of a disk radius a using polar coordinates. Area = ∫₀²π∫₀ᵃ r dr dθ = ∫₀²π(a²/2)dθ = πa².

15. Triple integrals and 3-D coordinate systems

A triple integral accumulates a function throughout a three-dimensional region. For a suitable region V:

\(\iiint_V f(x,y,z)\,dV\)

If f=1, the integral gives volume. If f is a density, it can give mass.

15.1 Cartesian coordinates

\(dV=dx\,dy\,dz\)

Set three nested limits that describe the solid. Draw or reason about the solid to avoid incorrect bounds.

15.2 Cylindrical coordinates

\(x=r\cos\theta,\ y=r\sin\theta,\ z=z,\quad dV=r\,dr\,d\theta\,dz\)

Useful for cylinders, circular pipes and solids with rotational symmetry about the z-axis.

15.3 Spherical coordinates

\(x=\rho\sin\phi\cos\theta,\ y=\rho\sin\phi\sin\theta,\ z=\rho\cos\phi\)
\(dV=\rho^2\sin\phi\,d\rho\,d\phi\,d\theta\)

Here ρ is radial distance, θ is the azimuthal angle in the xy-plane, and φ is measured down from the positive z-axis. State the convention used because some texts interchange angle names.

15.4 Choosing coordinates

GeometryLikely convenient coordinates
Rectangular box or plane-bounded solidCartesian.
Cylinder, circular cross-section, rotational symmetry about zCylindrical.
Sphere or spherical shellSpherical.
Volume of a cylinder: Radius a and height h. In cylindrical coordinates, V=∫₀ʰ∫₀²π∫₀ᵃ r dr dθ dz = h·2π·(a²/2)=πa²h.
Common error: Do not forget the Jacobian factors r in polar/cylindrical coordinates and ρ²sinφ in spherical coordinates. Omitting them changes the integral.

16. Computational tools and visualisation

The curriculum includes visualisation of functions, maxima/minima and evaluation of definite, indefinite, double and triple integrals using open-source software. A tool supports understanding; it does not replace the mathematical setup.

16.1 Suggested Scilab workflow

  1. Define the function and the interval or domain.
  2. Plot the function or surface using a suitable plotting command.
  3. Identify likely roots, stationary points or geometric boundaries.
  4. Perform symbolic or numerical calculations using a suitable available function/toolbox.
  5. Compare the software result with a hand calculation or independent check.
  6. Record software name/version, inputs, commands, output and interpretation.

For a graph, label axes and use an appropriate scale. For a numerical integral, check whether the result is plausible from sign, units and approximate area. Numerical output is an approximation and may depend on tolerance and method.

16.2 When to use software

  • Plot complicated functions to inspect behaviour.
  • Visualise surfaces and contour plots for functions of two variables.
  • Check candidate stationary points and compare function values.
  • Approximate integrals that are difficult to evaluate analytically.
  • Explore how changing a parameter changes a graph or optimum.

17. Exam preparation and problem presentation

17.1 Differentiation and extrema answer format

  1. Write the given function and domain.
  2. Differentiate correctly and find critical points.
  3. Apply the first/second derivative test or endpoint comparison.
  4. Show substitutions and evaluate the function.
  5. State whether the result is local or absolute.

17.2 Partial derivative answer format

  1. Write the function and state which variable is held constant.
  2. Differentiate term by term.
  3. For a chain rule question, draw or state the dependency between variables.
  4. Substitute values only after obtaining the derivative expression.

17.3 Integral answer format

  1. Identify the type: substitution, parts, definite, improper or geometric.
  2. Write the formula or substitution.
  3. Show antiderivative and apply limits in the correct order.
  4. For area/length/surface area, include the correct geometric formula and units.

17.4 Multiple integral answer format

  1. Sketch the region/solid and identify its boundaries.
  2. Choose coordinates that simplify the boundaries.
  3. Write the Jacobian and the correct limits.
  4. Integrate from inside outward, showing each step.
  5. Check whether the answer has the correct sign and physical dimension.
High-value revision: Practise the standard derivative/integral formulae, critical-point tests, chain rule, Lagrange equations, change of order, and coordinate Jacobians until you can set up the problem without looking at notes.
