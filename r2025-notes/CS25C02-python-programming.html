TOPIC 1

Introduction to Python and problem solving

1.1 What is Python?

Python is a high-level, general-purpose programming language. It is designed with readable syntax and supports procedural, object-oriented and functional programming styles. It is widely used for automation, data analysis, scientific computing, web applications and artificial intelligence.

1.2 Problem-solving sequence

  1. Understand the problem: identify the required output and the information supplied as input.
  2. Analyse the problem: identify the formula, conditions or logical steps needed.
  3. Design the solution: write an algorithm, flowchart or pseudocode.
  4. Write the program: translate the logic into Python statements.
  5. Test the program: use normal, boundary and unusual inputs.
  6. Debug and document: correct errors and add meaningful comments.

1.3 Algorithm, flowchart and pseudocode

AlgorithmA finite, ordered set of unambiguous steps to solve a problem.
FlowchartA graphical representation of program logic using standard symbols and arrows.
PseudocodeA language-independent description of the logic using structured statements.
ProgramThe executable implementation of the designed logic in a programming language.

1.4 Interactive mode and script mode

Interactive mode: statements are entered at the Python prompt and executed immediately. It is useful for quick experiments and checking expressions.

Script mode: statements are written in a file (usually with the .py extension) and executed as a program. It is suitable for complete programs, repeated execution and submission of practical work.

1.7 Input, output and type conversion

length = float(input("Enter length in metres: "))
width = float(input("Enter width in metres: "))

area = length * width
print("Area =", area, "m^2")

The input() function returns text. Convert it using int(), float() or another suitable conversion before performing numeric calculations.

Worked example: area of a rectangle

Problem: Read length and breadth and display area.

Algorithm: Start → Read L and B → Calculate A = L × B → Display A → Stop.

length = float(input("Length: "))
breadth = float(input("Breadth: "))
area = length * breadth
print("Area of rectangle =", area)

Sample input: 8 and 5. Output: Area of rectangle = 40.0

TOPIC 2

Control Structures

Control structures determine the order in which statements execute. Python uses indentation to define a block of statements. Statements belonging to the same block must use consistent indentation.

2.1 Conditional statements

mark = int(input("Enter mark: "))

if mark >= 50:
    print("Pass")
else:
    print("Fail")

if tests a condition. elif tests another condition when the earlier condition is false. else handles the remaining case.

Worked example: grade classification

mark = int(input("Enter mark: "))

if mark < 0 or mark > 100:
    print("Invalid mark")
elif mark >= 90:
    print("Grade O")
elif mark >= 80:
    print("Grade A+")
elif mark >= 70:
    print("Grade A")
elif mark >= 60:
    print("Grade B+")
elif mark >= 50:
    print("Grade B")
else:
    print("RA / Fail")

Reasoning: Test the highest range first. If lower limits are checked first, a mark of 95 could be incorrectly classified in a lower grade.

2.2 while loop

A while loop repeats as long as its condition remains true. Update the loop variable so that the loop eventually terminates.

n = 1
while n <= 5:
    print(n)
    n += 1

2.3 for loop

A for loop iterates over items in a sequence or other iterable. The range() function generates a sequence of integers.

for n in range(1, 6):
    print(n)
ExpressionGenerated values
range(5)0, 1, 2, 3, 4
range(2, 6)2, 3, 4, 5
range(1, 10, 2)1, 3, 5, 7, 9

2.4 Nested loops and jump statements

A nested loop is a loop inside another loop. It is useful for tables, patterns and two-dimensional data. break terminates the nearest loop; continue skips the remaining statements in the current iteration; pass is a placeholder statement that performs no action.

# Multiplication table from 1 to 3
for i in range(1, 4):
    for j in range(1, 6):
        print(i, "x", j, "=", i * j)
    print()
Common errors: forgetting the colon, incorrect indentation, using = instead of == in a condition, and creating an infinite while loop by failing to update the condition variable.
TOPIC 3

Functions

A function is a named, reusable block of code that performs a particular task. Functions reduce repetition, divide a large problem into manageable parts and make programs easier to test.

3.1 Defining and calling a function

def rectangle_area(length, breadth):
    area = length * breadth
    return area

result = rectangle_area(8, 5)
print("Area =", result)

def defines a function. The function name is followed by parentheses and a colon. The indented body contains the statements. A function call executes the function. return sends a result back to the caller.

3.2 Parameters and arguments

TermMeaning
Formal parameterName written in the function definition.
Actual argumentValue or expression supplied during the function call.
Return valueResult sent back using the return statement.
Named argumentArgument supplied using the parameter name.
def student_result(name, mark):
    print(name, "scored", mark)

student_result("Anu", 86)             # positional arguments
student_result(mark=86, name="Anu")   # named arguments

3.3 Recursion

Recursion occurs when a function calls itself. A recursive solution must contain a base case that stops further calls; otherwise the calls continue until Python raises a recursion-depth error.

def factorial(n):
    if n == 0 or n == 1:   # base case
        return 1
    return n * factorial(n - 1)

print(factorial(5))

For this example, 5! = 5 × 4 × 3 × 2 × 1 = 120.

3.4 Lambda functions

A lambda expression creates a small anonymous function containing a single expression.

square = lambda x: x * x
print(square(6))   # 36
Exam presentation: For a function question, show the function definition, explain each parameter, show the function call, and state the output. If recursion is asked, clearly identify the base case and recursive case.
TOPIC 4

Strings and Collections

4.1 Strings

A string is an immutable sequence of characters. Strings can be created using single, double or triple quotes. Indexing starts at zero; negative indexing counts from the end.

word = "ENGINEER"
print(word[0])       # E
print(word[-1])      # R
print(word[1:4])     # NGI
print(len(word))     # 8

Common string operations

ComparisonCompare strings lexicographically."abc" == "abc"

SlicingExtract a portion.s[1:5]
split()Divide a string into a list."a,b".split(",")
strip()Remove leading/trailing whitespace or specified characters." hi ".strip()
replace()Return a string with occurrences replaced.s.replace("a","b")

4.2 Lists

A list is an ordered, mutable collection. It can contain elements of different data types. Lists are written using square brackets.

marks = [72, 85, 68, 91]
marks.append(78)
marks[0] = 75

print(marks)
print("Maximum =", max(marks))
print("Total =", sum(marks))

Common methods include append(), extend(), insert(), remove(), pop(), sort() and reverse().

4.3 Tuples

A tuple is an ordered, immutable collection. It is suitable for values that should remain fixed after creation.

point = (12, 8)
x, y = point
print("x =", x, "y =", y)

4.4 Sets

A set is an unordered collection of unique elements. Duplicate values are removed. Sets support union, intersection and difference operations.

A = {1, 2, 3, 4}
B = {3, 4, 5, 6}
print(A | B)   # union
print(A & B)   # intersection
print(A - B)   # difference

4.5 Dictionaries

A dictionary stores values as key-value pairs. Keys are unique and are used to access the associated values.

student = {"name": "Meena", "mark": 88}
student["department"] = "ECE"
student["mark"] = 92
del student["department"]

print(student["name"])
print(student)

4.6 Searching and sorting a list

numbers = [34, 12, 56, 23, 9]

# Linear search
target = 23
found = False
for value in numbers:
    if value == target:
        found = True
        break

print("Found" if found else "Not found")

# Sorting
numbers.sort()
print(numbers)
Do not confuse: Lists are mutable; tuples are immutable; sets keep unique elements; dictionaries map keys to values. A string is immutable even though individual characters can be accessed by index.
TOPIC 5

File Operations

File handling allows a program to store information permanently and retrieve it later. The general sequence is open a file, perform the required operation, and close the file. The with statement is recommended because it closes the file automatically when the block finishes.

5.1 File modes

ModeMeaningImportant behaviour
rReadFile must already exist.
wWriteCreates a file or overwrites existing contents.
aAppendAdds data at the end; creates the file if needed.
xExclusive creationFails if the file already exists.
bBinary modeUsed with another mode, such as rb.
tText modeDefault mode for ordinary text files.

5.2 Writing and reading a text file

# Write
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Python programming\n")
    file.write("File handling example\n")

# Read
with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()

print(content)

5.3 Append and line-by-line reading

with open("marks.txt", "a", encoding="utf-8") as file:
    file.write("Kumar,85\n")

with open("marks.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())

5.4 CSV files

CSV (comma-separated values) files store tabular data as rows. Python's csv module provides tools to read and write CSV data.

import csv

rows = [
    ["Name", "Mark"],
    ["Anu", 88],
    ["Kumar", 76]
]

with open("students.csv", "w", newline="", encoding="utf-8") as file:
    writer = csv.writer(file)
    writer.writerows(rows)

with open("students.csv", "r", newline="", encoding="utf-8") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)

5.5 OS and sys modules

The os module provides functions for interacting with the operating system, such as working with directories and file paths. The sys module provides access to interpreter and system-specific parameters.

import os
import sys

print("Current directory:", os.getcwd())
print("Python version:", sys.version)
TOPIC 6

Modules and Packages

A module is a Python file containing reusable definitions and statements. A package organises related modules. Importing a module makes its functions and classes available to a program.

import math
print(math.sqrt(81))
print(math.pi)

from math import factorial
print(factorial(5))
PackageMain useTypical engineering application
NumPyNumerical arrays and mathematical operations.Vector calculations, matrices and numerical data.
SciPyScientific algorithms.Optimisation, integration, interpolation and signal processing.
PandasTabular data handling and analysis.Reading experimental data, cleaning data and summarising results.
Scikit-learnMachine-learning tools.Classification, regression, clustering and model evaluation.

Built-in, standard and user-defined modules

  • Built-in functions: functions available directly, such as print(), len() and type().
  • Standard library modules: modules supplied with Python, such as math, os, sys and csv.
  • User-defined modules: Python files created by the programmer and imported into another program.
  • Third-party packages: packages installed separately, such as NumPy, SciPy, Pandas and Scikit-learn.
Practical preparation: For every package named in the syllabus, know its purpose, import statement and at least one small application. Do not memorise a package name without understanding what problem it solves.
EXAM PROGRAM-WRITING METHOD

How to present a programming answer

  1. State the logic: explain what the program must calculate or decide.
  2. Write the algorithm: use short, numbered steps.
  3. Write the program: use meaningful variable names, correct indentation and comments where useful.
  4. Show sample input and output: choose values that make the result easy to verify.
  5. Explain the key statements: describe the condition, loop, function or data structure that performs the main task.
  6. Test boundary cases: consider zero, negative values, empty input or values at the condition limit where relevant.
Common mistakes: incorrect indentation; forgetting that input() returns a string; off-by-one errors in range(); missing a recursion base case; modifying a collection while iterating over it; and opening a file in write mode when the intention is to append.
