PART A — 2-Mark Answers

1. Primary coordinate system
The Cartesian coordinate system is the primary coordinate system, normally represented by X, Y and Z axes in 3D computer graphics.
2. Clipping vs viewing
Viewing defines how a scene is transformed and projected into the viewing/display space. Clipping removes portions of objects lying outside the selected viewing region.
3. Analytical, interpolated and approximated curves
Analytical curves are defined by exact mathematical equations. Interpolated curves pass through specified data/control points. Approximated curves are controlled by points but generally do not pass through every control point.
4. B-spline characteristics
Local control, piecewise polynomial definition, continuity controlled by degree/knot vector, generally does not pass through all control points, and stable geometric manipulation.
5. Ray tracing
A ray is traced from the viewing point through each image pixel into the scene. Ray-object intersections are found; the nearest visible surface is selected and secondary rays can be used for reflection, refraction and shadows.
6. Warnock's Algorithm
It recursively subdivides the viewing area into smaller regions until the visibility of the polygons in a region can be resolved directly or the region reaches a simple case/pixel level.
7. FEM stiffness matrix
The element stiffness matrix relates nodal displacements to nodal forces: {F}e = [k]e{u}e. It represents the resistance of an element to deformation.
8. Shape-function properties
They should provide the required interpolation, satisfy nodal interpolation (Kronecker-delta property for standard nodal elements), maintain compatibility/continuity as required, and reproduce the field adequately within the element.
9. Ritz Method in FEA
An admissible approximate displacement/field function is assumed with unknown coefficients. The governing functional is made stationary, usually by setting its derivatives with respect to the unknown coefficients to zero, producing algebraic equations.
10. Good mesh quality
Poorly shaped or distorted elements can reduce accuracy and cause convergence problems. A suitable mesh improves numerical reliability and captures important gradients without unnecessary computational cost.

PART B — 13-Mark Answers

11(a). Sutherland–Hodgman Polygon Clipping

The Sutherland–Hodgman method clips a polygon against each boundary of a convex clipping window successively.

  1. Take the polygon vertices in order.
  2. Process them against the first clipping boundary.
  3. For each consecutive pair, classify the start and end vertices as inside/outside.
  4. Apply the four cases: inside→inside: output end point; inside→outside: output intersection; outside→inside: output intersection and end point; outside→outside: output nothing.
  5. Use the resulting polygon as input for the next boundary.
  6. After all boundaries, the remaining vertices form the clipped polygon.

Advantages: systematic, simple, efficient for convex clipping windows, and suitable for polygon graphics pipelines.

Limitations: basic form is intended for convex clipping regions; concave/general cases require additional handling and generated vertex ordering must be managed carefully.

13(b). Hidden-surface removal

Hidden-surface removal determines which surfaces are visible from the chosen viewpoint and prevents surfaces behind nearer surfaces from being displayed.

Depth-buffer method: maintain a depth value for each pixel; when a new fragment is closer than the stored depth, replace the stored depth and colour.

Warnock method: recursively subdivide a viewing area when the visibility of overlapping polygons cannot be resolved at the current region size. Continue until a simple visibility case is obtained.

Other methods include scan-line, priority/depth sorting and ray tracing.

14(a). Step-by-step FEM procedure
  1. Define the physical problem and assumptions.
  2. Idealise the geometry and loading.
  3. Discretise the domain into finite elements.
  4. Select element type and interpolation/shape functions.
  5. Specify material properties.
  6. Apply loads and boundary conditions.
  7. Form each element equation/stiffness matrix.
  8. Assemble the global stiffness matrix.
  9. Apply essential boundary conditions.
  10. Solve for unknown nodal displacements/temperatures.
  11. Calculate strains, stresses, reactions or other derived quantities.
  12. Check mesh sensitivity and physical reasonableness.

The supplied paper's truss problem in Q14(b) is a direct example of this sequence.

15(b). Geometric nonlinearity
Geometric nonlinearity occurs when deformation changes the geometry sufficiently that the equilibrium equations and stiffness depend on the current configuration. Important factors include large displacement, large rotation, changing load direction/configuration, stress-stiffening effects and instability/buckling-type behaviour. An incremental-iterative nonlinear solution is commonly required.

PART C — 15-Mark Answers

16(a). Rayleigh–Ritz deflection

For a cantilever of length L and flexural rigidity EI, choose an admissible trial function satisfying the fixed-end conditions:

v(x)=a x²(3L−x)

For a uniformly distributed load w over the full span and a point load P at x=L/2, the Ritz functional is U−W. The required integrals are:

∫₀ᴸ(φ″)²dx=12L³,   ∫₀ᴸφdx=3L⁴/4,   φ(L/2)=5L³/8

Hence:

a = wL/(16EI) + 5P/(96EI)

Deflection at the centre:

vRitz(L/2)=5wL⁴/(128EI)+25PL³/(768EI)

For comparison, the exact centre deflection is obtained by superposition:

vexact(L/2)=5wL⁴/(384EI)+PL³/(24EI)

The difference arises because the selected single trial function cannot reproduce the exact piecewise curvature field produced by the centre point load.
