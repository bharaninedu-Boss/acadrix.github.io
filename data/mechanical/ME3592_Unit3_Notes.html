1. Why Tolerancing Is Necessary

No manufacturing process can produce every component at exactly one mathematical dimension. Variation occurs because of machine accuracy, tool wear, temperature, material variation, operator effects and process capability. Tolerancing defines the permitted variation while preserving function, interchangeability and economical manufacture.

Function
Ensures the part performs its intended job.
Interchangeability
Allows mating parts to be assembled without individual fitting.
Manufacturing economy
Avoids unnecessarily tight tolerances and excessive inspection cost.
Quality control
Provides acceptance limits for inspection.
Assembly
Controls clearance, transition or interference between mating parts.
Reliability
Keeps functional variation within an acceptable range.

4. Interchangeability

Interchangeability means that mating components manufactured within their specified limits can be assembled without selective hand fitting and still perform the intended function.

4.1 Local and universal interchangeability

  • Local interchangeability: components are interchangeable within a particular production group or assembly arrangement.
  • Universal interchangeability: any acceptable mating component from the specified production system can be assembled with another acceptable component.

4.2 Advantages

  • Mass production becomes practical.
  • Assembly time is reduced.
  • Replacement parts can be supplied easily.
  • Inspection and quality control can be standardized.
  • Repair and maintenance become easier.

5. Selective Assembly

In selective assembly, components are measured, classified into suitable size groups and then matched so that the final assembly meets the required functional condition. It can improve assembly performance when a very tight overall assembly tolerance would otherwise be uneconomical to manufacture for every individual component.

Manufactured parts → Measure → Classify into size groups → Match compatible groups → Assemble → Check function
Example: Suppose shafts and holes are produced with controlled but relatively broad tolerances. Instead of randomly assembling every shaft with every hole, measured components can be grouped as small/medium/large and matched appropriately. The final assembly can then satisfy the required clearance more consistently.

6. Limits and Fits

A fit describes the relationship between a hole and a shaft having the same basic size. The three principal types are clearance fit, transition fit and interference fit.

FitConditionTypical purpose
ClearanceHole is always larger than shaft.Free or sliding movement.
TransitionDepending on actual sizes, small clearance or small interference may occur.Accurate location with limited movement.
InterferenceShaft is always larger than hole.Permanent or tight assembly.

6.1 Fundamental fit calculations

Minimum clearance = Minimum hole size − Maximum shaft size
Maximum clearance = Maximum hole size − Minimum shaft size
Maximum interference = Maximum shaft size − Minimum hole size
Minimum interference = Minimum shaft size − Maximum hole size

7. Full-Working Problem — Classify a Fit

Given: A hole has limits 40.000 to 40.025 mm. A shaft has limits 39.980 to 39.995 mm. Determine maximum clearance, minimum clearance and the type of fit.
Step 1 — Write the limits.
Maximum hole = 40.025 mm
Minimum hole = 40.000 mm
Maximum shaft = 39.995 mm
Minimum shaft = 39.980 mm
Step 2 — Maximum clearance.
Cmax = Hmax − Smin = 40.025 − 39.980 = 0.045 mm
Step 3 — Minimum clearance.
Cmin = Hmin − Smax = 40.000 − 39.995 = 0.005 mm
Step 4 — Classify.
Both minimum and maximum clearances are positive. Therefore, the fit is a clearance fit.
Final answer: Maximum clearance = 0.045 mm; minimum clearance = 0.005 mm; fit = clearance fit.

8. Hole-Basis and Shaft-Basis Systems

In a hole-basis system, the basic hole condition is kept fixed and different shaft limits are selected to obtain the required fits. In a shaft-basis system, the basic shaft condition is kept fixed and different hole limits are selected.

Hole basisShaft basis
Basic hole is maintained as the reference condition.Basic shaft is maintained as the reference condition.
Different shaft tolerance positions produce different fits.Different hole tolerance positions produce different fits.
Widely used where standard hole-making tools influence manufacturing practice.Useful when shaft size or standard shaft conditions govern the application.

9. IS 919 Table Problems — Correct Method

For a standard fit designation, the problem normally requires the student to use the applicable IS 919 table to obtain the fundamental deviation and tolerance values for the specified basic size, tolerance grade and position. Do not guess these values.

Step 1: Identify the basic size.
Step 2: Identify the hole/shaft designation and tolerance grade.
Step 3: From the authorized IS 919 table, obtain the required deviations/tolerance values.
Step 4: Calculate upper and lower limits.
Step 5: Calculate maximum/minimum clearance or interference.
Step 6: State the type of fit and interpret it.
Exam warning: Never invent an IS 919 table value from memory when solving a numerical. If the question supplies a table, use that table. If a table is not available, state the required table lookup instead of manufacturing a value.

10. Limit Gauges

A limit gauge checks whether a manufactured feature lies within specified limits without directly measuring and displaying its exact dimension. It is especially useful for rapid inspection in production.

10.1 Types

Plug gauge
Used mainly for checking holes/internal dimensions.
Ring gauge
Used mainly for checking shafts/external dimensions.
Snap gauge
Used for rapid checking of external dimensions.
Thread gauges
Used for checking specified threaded features.

10.2 GO and NO-GO principle

GO gauge → should pass the feature under the specified checking condition.

NO-GO gauge → should not pass the feature under the specified checking condition.

The purpose is acceptance/rejection rather than obtaining a numerical measurement. Gauge design must account for the workpiece limits and the applicable gauge-design rules.

11. Taylor's Principle

Taylor's principle provides the fundamental functional idea for GO and NO-GO gauging. The GO gauge represents the maximum-material condition and checks the related feature in a way that verifies the combined dimensional/form requirement. The NO-GO gauge checks the relevant limit without being permitted to enter in the same manner as the GO gauge.

For a 12-mark answer: Do not stop at “GO passes and NO-GO does not.” Explain maximum-material condition, functional checking, separate GO/NO-GO roles, production-inspection advantage and the need to follow the specified gauge-design rules.

12. Full-Working Gauge Design Problem — Method

Problem type: Design a GO/NO-GO gauge for a specified hole or shaft when the component limits and gauge-design data are given.
Step 1 — Determine component limits.
Write the maximum and minimum workpiece dimensions clearly.
Step 2 — Identify feature type.
Decide whether the gauge checks a hole or an external feature.
Step 3 — Apply the specified gauge-design rule.
Use the gauge tolerance, wear allowance and other values given in the problem or prescribed design data.
Step 4 — Determine GO gauge size.
Calculate the gauge limit corresponding to the maximum-material condition using the supplied rules.
Step 5 — Determine NO-GO gauge size.
Calculate the appropriate limit for the opposite inspection condition.
Step 6 — Present the final dimensions.
Clearly label GO and NO-GO gauge dimensions and state the checking condition.
Exact numerical gauge tolerances and wear allowances depend on the data/table specified in the problem. Do not insert an unverified standard value.

13. Tolerance Analysis in Manufacturing

Tolerance analysis studies how individual dimensional variations combine and influence a functional requirement, assembly dimension or product performance.

13.1 Objectives

  • Predict assembly variation.
  • Identify critical dimensions.
  • Allocate tolerances rationally.
  • Prevent functional failure caused by accumulated variation.
  • Balance manufacturing cost and functional requirement.

13.2 Basic procedure

  1. Define the functional requirement.
  2. Identify all dimensions contributing to it.
  3. Establish the dimensional loop and sign convention.
  4. Collect nominal dimensions and tolerances.
  5. Choose a stack-up method appropriate to the problem.
  6. Calculate the worst-case or statistical result as requested.
  7. Compare with the functional requirement.
  8. Redistribute tolerances if necessary.

14. Tolerance Stack-Up

Tolerance stack-up is the accumulation of individual dimensional tolerances that affects a final assembly dimension or functional gap.

14.1 Worst-case stack-up

For a simple linear chain where independent dimensional contributions all add in the worst direction:

Ttotal = T1 + T2 + T3 + … + Tn

This approach ensures the specified functional requirement is satisfied even when all contributors simultaneously approach their limiting conditions, but it can lead to conservative tolerance allocation.

14.2 Root-sum-square form

When the problem explicitly asks for a statistical/independent variation approach and the assumptions are appropriate:

TRSS = √(T12 + T22 + … + Tn2)

Use the exact convention and statistical assumptions specified by the question. Do not automatically replace worst-case analysis with RSS.

15. Full-Working Tolerance Stack-Up Problem

Given: An assembly gap is controlled by three dimensions with tolerance magnitudes of ±0.10 mm, ±0.05 mm and ±0.08 mm. Find the worst-case total tolerance.
Step 1 — List individual tolerance magnitudes.
T1 = 0.10 mm
T2 = 0.05 mm
T3 = 0.08 mm
Step 2 — Apply worst-case stack-up.
Ttotal = 0.10 + 0.05 + 0.08 = 0.23 mm
Step 3 — Interpret.
If the nominal functional gap is G, the worst-case limits are determined by combining the nominal value with the calculated total variation according to the dimension-loop sign convention.
Final answer: Worst-case accumulated tolerance magnitude = 0.23 mm.

16. Process Capability

Process capability evaluates whether a stable manufacturing process can produce output within specified tolerance limits. The analysis compares process variation and centering with the specification limits.

Cp = USL − LSL6σ
Cpk = min USL − μ3σ , μ − LSL3σ

USL = upper specification limit, LSL = lower specification limit, μ = process mean and σ = process standard deviation.

16.1 Interpretation

  • Cp compares the specification width with process spread but does not indicate whether the process is centered.
  • Cpk considers both spread and centering.
  • A process may have a good Cp but a lower Cpk if its mean is displaced toward one specification limit.
  • Capability analysis should be interpreted only when the assumptions and process conditions are appropriate.

17. Full-Working Process Capability Problem

Given: USL = 50.30 mm, LSL = 49.70 mm, process mean μ = 50.00 mm and σ = 0.05 mm. Find Cp and Cpk.
Step 1 — Calculate Cp.
Cp = 50.30 − 49.706(0.05) = 0.600.30 = 2.00
Step 2 — Calculate upper capability index.
Cpu = 50.30 − 50.003(0.05) = 0.300.15 = 2.00
Step 3 — Calculate lower capability index.
Cpl = 50.00 − 49.703(0.05) = 0.300.15 = 2.00
Step 4 — Find Cpk.
Cpk = min(2.00, 2.00) = 2.00
Final answer: Cp = 2.00 and Cpk = 2.00. The given process is centered between the specification limits, and the calculated capability indices indicate a process spread much smaller than the specification width under the stated assumptions.

18. Tolerance Charting

A tolerance chart represents the dimensional relationships in an assembly or manufacturing sequence so that the accumulation of dimensions and tolerances can be analyzed systematically.

18.1 Procedure

  1. Identify the final functional dimension.
  2. Identify all component dimensions contributing to it.
  3. Draw the dimensional chain in a consistent direction.
  4. Assign nominal dimensions and tolerances.
  5. Mark positive and negative contributors according to the chain.
  6. Calculate the resulting limits or total tolerance.
  7. Compare the result with the functional requirement.
  8. Revise tolerance allocation where required.
Reference datum → Dimension A → Dimension B → Dimension C → Functional gap
Each dimension contributes to the final functional relationship.

19. Tolerance Analysis — 12-Mark Answer

Question: Explain tolerance analysis in manufacturing.

Introduction: Manufacturing processes produce dimensional variation. Tolerance analysis determines how individual tolerances affect a final functional dimension or assembly.

1. Define functional requirement: Identify the required gap, alignment, clearance, location or other performance condition.

2. Identify contributors: List every dimension that enters the dimensional chain.

3. Establish dimensional loop: Select a reference/datum and assign the sign of each contributor.

4. Determine limits: Calculate maximum and minimum dimensions from the specified tolerances.

5. Perform stack-up: Use worst-case analysis or an appropriate statistical method according to the problem.

6. Evaluate result: Compare the calculated assembly limits with the functional requirement.

7. Optimize: If the assembly requirement is not met, identify critical contributors and redistribute tolerances without compromising function.

Manufacturing significance: Proper tolerance analysis prevents over-tolerancing, reduces unnecessary manufacturing cost, improves interchangeability and helps identify critical dimensions.

Conclusion: Tolerance analysis connects design requirements with manufacturing capability and assembly performance.

📚 Detailed Theory — Unit III

1. Tolerance Terminology

Basic size is the theoretical size from which limits and deviations are derived. Actual size is the measured size. Limits are the maximum and minimum permissible sizes. Tolerance is the difference between the limits. Allowance is the intentional difference between mating features at maximum material condition as defined by the fit system.

In numerical answers, write all these values before classifying the fit.

2. Limits, Fits and Tolerance Zones

A fit describes the relationship between mating hole and shaft dimensions. Clearance fit always provides clearance; interference fit always provides interference; transition fit may produce either depending on actual sizes.

Hole-basis and shaft-basis systems use one member as the reference basis. Draw tolerance zones relative to the zero line for high-scoring theory answers.

3. Interchangeability

Interchangeability means mating parts manufactured within specified limits can be assembled without individual fitting or modification beyond the defined manufacturing/assembly system. It is essential for mass production, maintenance and replacement.

Selective assembly may be used when complete interchangeability is not economical or when tighter functional matching is required. Explain the manufacturing and inspection implications.

4. GO/NO-GO Gauges

Limit gauges are used to decide whether a manufactured feature lies within specified limits. A GO gauge checks the condition associated with maximum material, while the NO-GO gauge checks the opposite limit condition, subject to the feature and gauge convention.

Taylor's principle is used to define the functional GO condition so that the relevant maximum-material boundary is checked appropriately; the NO-GO check is intended to check the other limit without falsely accepting an out-of-limit feature.

For design numericals, first calculate workpiece limits, then apply the gauge-tolerance and wear rules explicitly stated by the question. Never invent a percentage if none is supplied.

5. Tolerance Stack-Up

Tolerance stack-up is the accumulation of individual dimensional variations in an assembly. In worst-case analysis, limiting variations are combined directly according to the dimension chain. Statistical/RSS approaches combine independent variations differently and require appropriate assumptions.

6. Process Capability

Process-capability indices relate process spread and centring to specification limits. Common indices include Cp for potential capability and Cpk for capability considering process centring. State the specification limits, process mean and spread used, and do not interpret capability indices without considering the stability/assumptions of the process.
