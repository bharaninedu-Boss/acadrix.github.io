Problem 1 — Straightness from Measured Deviations

Given: Measured deviations along a line are +0.02, −0.01, +0.04, +0.01 and −0.03 mm.
Step 1 — Maximum deviation
dmax = +0.04 mm
Step 2 — Minimum deviation
dmin = −0.03 mm
Step 3 — Observed variation
Variation = dmax − dmin = 0.04 − (−0.03) = 0.07 mm
Answer: Observed straightness variation = 0.07 mm. Compare this value with the specified straightness tolerance and the assessment method given in the question.

Problem 2 — Flatness Inspection Logic

Problem: A surface has a specified flatness tolerance. Explain how the measured surface is checked.
  1. Clean the component and inspection surface.
  2. Set up the part using the required measurement method.
  3. Measure points over the specified surface area using a suitable instrument.
  4. Determine the maximum separation/deviation according to the selected assessment method.
  5. Compare the observed flatness error with the drawing tolerance.
  6. Record the result and measurement conditions.
Key point: Flatness controls a surface within a tolerance zone bounded by two parallel planes; the exact numerical acceptance method must follow the specified inspection procedure.

Problem 3 — Roundness Inspection

Problem: Describe the calculation/inspection sequence for a circular section whose roundness tolerance is specified.
  1. Select the required cross-sectional plane.
  2. Align and centre the component.
  3. Rotate the part or probe through the required range.
  4. Record radial displacement/profile data.
  5. Evaluate the profile using the specified roundness criterion.
  6. Compare the resulting roundness error with the specified tolerance.
Exam point: Do not treat roundness as the same as straightness or flatness. State the controlled geometry and show a labelled inspection sketch.

Problem 4 — Surface Parameter: Ra

Given: A measured profile is represented by deviations y(x) from its mean line over evaluation length L.
Ra = (1/L) ∫0L |y(x)| dx
Answer: Ra is the arithmetic mean of the absolute profile deviations from the mean line over the specified evaluation length. In a numerical problem, substitute the supplied profile data or segment values into the stated evaluation relation.

Problem 5 — Stylus Surface-Finish Measurement

Problem: Write the complete measurement sequence for determining a surface-finish parameter with a stylus instrument.
  1. Clean and position the workpiece.
  2. Select the correct traverse direction and measurement conditions.
  3. Bring the stylus into controlled contact with the surface.
  4. Traverse the specified length at the specified speed.
  5. Convert stylus displacement into an electrical signal using the pickup/transducer.
  6. Amplify and process the signal.
  7. Apply the required filtering/evaluation conditions.
  8. Calculate the selected parameter such as Ra.
  9. Display and record the result together with measurement conditions.
Block diagram: Surface → Stylus → Pickup/Transducer → Amplifier → Filter → Parameter calculation → Display

Problem 6 — Comparative Surface-Finish Measurement

Problem: Explain how a manufactured surface is compared with reference specimens.
  1. Select reference specimens covering the expected surface-texture range.
  2. Clean the test surface and reference specimens.
  3. Compare under controlled viewing/tactile conditions.
  4. Identify the closest matching reference or range.
  5. Record the result and relevant process information.
Result: Comparative measurement is quick and inexpensive but is subjective and operator-dependent; it does not provide the same quantitative profile data as an instrumented method.

Problem 7 — Filter and Cut-Off Selection

Problem: Explain why filtering and cut-off are important when evaluating surface roughness.
  1. A measured profile contains components with different wavelengths.
  2. The evaluation method separates appropriate wavelength components.
  3. Cut-off defines the wavelength boundary used for the selected evaluation.
  4. Evaluation length and filter settings affect the reported roughness value.
  5. The same measurement conditions should be maintained when comparing surfaces.
Answer: Filtering is part of defining the profile being evaluated; it is not simply an optional noise-removal step.

Problem 8 — 3D Surface Parameter: Sa

Problem: Explain the meaning and calculation basis of the areal parameter Sa.
Sa = (1/A) ∬A |z(x,y)| dA
Answer: Sa is the arithmetic mean of absolute height deviations from the mean plane over the assessed area. It is an areal parameter and should not be confused with Ra, which is a profile parameter.

Problem 9 — Optical Surface Measurement

Problem: State the measurement workflow for an optical/non-contact surface method.
Light source → Surface → Optics/Detector → Signal/Image processing → Surface information
  1. Illuminate the surface under controlled conditions.
  2. Acquire optical information using the selected sensor.
  3. Process the captured signal/image.
  4. Extract the required surface geometry or texture information.
  5. Evaluate the result using the specified measurement convention.
Advantages: non-contact measurement and suitability for delicate surfaces. Limitations: reflectivity, transparency, contamination, lighting and optical alignment can affect results.

Problem 10 — GD&T and Datum Reference

Problem: Explain how GD&T and datums are used when inspecting a component.
  1. Identify the geometric requirement on the drawing.
  2. Identify the datum feature(s) and establish the datum reference frame.
  3. Align the component to the required reference condition.
  4. Measure the controlled feature using a suitable instrument.
  5. Evaluate the measured geometry against the specified tolerance zone.
  6. Report the deviation and acceptance result according to the drawing requirement.
Key distinction: A physical datum feature is used to establish a theoretical datum reference; GD&T then communicates allowable geometric variation relative to the specified reference system.
